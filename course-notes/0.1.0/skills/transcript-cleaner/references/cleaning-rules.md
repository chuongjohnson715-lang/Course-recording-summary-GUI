# 清洗规则细则

本文件是 transcript-cleaner 第 2 步的完整规则库。执行清洗时按需加载本文件。

## 1. 口水词删除清单

### 可直接删除（纯填充，不携带任何判断信息）

- 单字填充：嗯、啊、呃、哦（句首应答除外）、唉
- 叠词填充：那个那个、就是就是、然后然后、这个这个
- 口头连接：就是说（句中纯填充时）、那个（非指代时）、然后呢（纯填充时）
- 口头禅：对吧（纯口头禅且非真实提问时）、哈（句尾语气）、啊（句尾语气）
- 重复词：同一词无意义重复 2 次以上时保留 1 次（"我们我们来看" → "我们来看"）

### 绝对保留（判断信号词，删除会改变下游置信度判断）

| 类别 | 词 | 影响 |
|------|-----|------|
| 不确定性 | 可能、大概、也许、好像、似乎、估计、听说 | 下游 judgment 归为"可能"类 |
| 确定性 | 一定、肯定、必须、绝对、明确 | 下游 judgment 归为"明确"类 |
| 强调 | 非常、特别、尤其、关键、重点、重要 | 下游 teacher_emphasis 信号 |
| 考试指向 | 会考、考过、出题、考点、考试、期末、期中、测验、小测 | 下游 assessment 信号 |
| 主观判断 | 我觉得、我认为、我建议 | 区分老师观点与客观安排 |

### 删除示例

```
原文：嗯，那个那个，我们今天啊，就是讲那个 MapReduce，对吧，这个东西可能期末会考。
清洗：今天我们讲 MapReduce，这个东西可能期末会考。
说明：删"嗯/那个那个/啊/就是/那个/对吧"；保留"可能期末会考"——这是考试信号。
```

## 2. 常见 ASR 识别错误修正表

### 通用错误（中文口语场景）

| 识别结果 | 应为 | 判定条件 |
|----------|------|----------|
| 的/得/地 混用 | 按语法修正 | 任何场景 |
| 在/再 混用 | 按语法修正 | 任何场景 |
| 做/作 混用 | 按语法修正 | 任何场景 |
| 他/她/它 | 按上下文 | 不影响成绩信息时可不标注 |
| 权利/权力、制定/制订 | 按上下文 | 高置信才改 |

### 计算机/大数据课程术语（按需扩充）

| 识别结果 | 应为 | 备注 |
|----------|------|------|
| 海杜普 / 哈杜普 / 哈道普 | Hadoop | 典型音译错误 |
| 洗牌机制 | Shuffle 机制 | 仅当上下文为 MapReduce 时修正 |
| 麦普瑞丢斯 / 麦普 reduce | MapReduce | |
| H D F S（逐字母拼读） | HDFS | 合并书写 |
| 斯巴克 | Spark | |
| 卡夫卡 | Kafka | |
| 神精网络 / 神经网咯 | 神经网络 | |
| 卷积神经网 | 卷积神经网络 | 补全 |
| 梯度下推 | 梯度下降 | |
| 过你和 / 过你合 | 过拟合 | |
| 大语言魔性 | 大语言模型 | |
| 皮托 / 派 torch | PyTorch | |
| 腾系统 | 系统（按上下文） | 示例，谨慎使用 |

**术语修正边界**：只有上下文明确属于该技术领域时才修正。"洗牌"在打比方场景（"像洗牌一样打乱"）不一定是 Shuffle——上下文明确讲 MapReduce Shuffle 阶段时才修正，否则保留原文并标 `[识别存疑:洗牌]`。

### 数字与日期类

- ASR 常把口语数字转错："二十六号" vs "二十号"。**日期、时间、分数、百分比一律不修正**——原样保留；若与上下文矛盾（如"下周一"与"26 号"对不上），标 `[识别存疑:原文，疑似日期]`，交给下游 pending_confirmations。

## 3. 低置信度标记规范

| 标记 | 使用场景 | 示例 |
|------|----------|------|
| `[听不清]` | 音频模糊，ASR 输出明显乱码或空缺 | "作业截止时间 `[听不清]` 之前交" |
| `[识别存疑:原文]` | 有转录文字但语义不通，且无法确定正确词 | "Shuffle `[识别存疑:换牌]` 阶段" |
| `⚠️[低置信度片段]` | 整段转录质量差，仅能大意参考 | 段尾标记 |

**禁止行为**：看到 `[听不清]` 就根据上下文"合理推测"填上内容。推测内容即使看起来 99% 正确也禁止填入正文；可在「清洗说明」中注明"该处疑似为 XX，供人工核对"。

## 4. 分段参考标准

- 小节标题取自老师讲授的主题切换信号："接下来我们看"、"再讲一个"、"下面这个"、"然后是"。
- 小节时长无硬性要求，但单个小节超过 20 分钟时考虑拆分。
- 每个语义单元（老师讲完一个完整意思）起新段落并带时间戳。

## 5. 清洗说明（文件末尾）模板

```markdown
## 清洗说明

- 删除口水词：N 处
- 修正识别错误：N 处（详见正文 `[原:xxx]` 标注）
- 识别存疑：N 处 → 位置：12:33 / 45:07 …
- 听不清：N 处 → 位置：…
- 疑似推测供人工核对（未写入正文）：……
```
